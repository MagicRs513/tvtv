# HBuilderX 开发指南

## 项目导入

### 方法一: 从本地目录导入
1. 打开 HBuilderX
2. 点击菜单 "文件" -> "导入" -> "从本地目录导入"
3. 浏览并选择 `LunaTV-Frontend` 项目根目录
4. 点击 "选择文件夹" 完成导入

### 方法二: 从 Git 仓库导入
1. 点击菜单 "文件" -> "导入" -> "从 Git 仓库导入"
2. 输入仓库地址
3. 点击 "导入"

## 依赖安装

### 使用 HBuilderX 终端
1. 在项目上右键,选择 "在终端中打开"
2. 执行以下命令:
```bash
npm install
```

### 使用外部终端
也可以在系统终端中进入项目目录执行:
```bash
cd /path/to/LunaTV-Frontend
npm install
```

## 运行项目

### H5 运行 (推荐用于调试)

#### 在浏览器中运行
1. 点击菜单 "运行" -> "运行到浏览器"
2. 选择浏览器 (Chrome/Edge/Firefox)
3. 项目将在浏览器中自动打开

#### 在内置浏览器中运行
1. 点击工具栏的 "运行" 按钮 (播放图标)
2. 或按快捷键 `Ctrl + R` (Windows) / `Cmd + R` (Mac)

### 微信小程序运行

#### 准备工作
1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 注册微信小程序账号
3. 在微信开发者工具中登录

#### 运行步骤
1. 在 HBuilderX 中点击 "运行" -> "运行到小程序模拟器" -> "微信开发者工具"
2. 微信开发者工具将自动打开并加载项目
3. 确认项目设置后即可预览

#### 注意事项
- 需要在 `manifest.json` 中配置微信小程序 `appid`
- 某些功能在小程序中可能受限,需要使用小程序专属 API

### APP 运行

#### 真机运行
1. 连接手机 (USB 调试模式已开启)
2. 在 HBuilderX 中点击 "运行" -> "运行到手机或模拟器"
3. 选择已连接的设备
4. HBuilderX 将自动安装并运行应用

#### 模拟器运行
1. 下载并安装 Android/iOS 模拟器
2. 在 HBuilderX 中点击 "运行" -> "运行到手机或模拟器"
3. 选择模拟器设备

### 电视端运行

#### 通过 HDMI 连接
1. 使用 HDMI 线连接电脑和电视
2. 将电视设为显示输入源
3. 在 HBuilderX 中运行 H5 版本
4. 在电视上全屏显示浏览器

#### 使用远程调试工具
1. 在电视上打开支持远程调试的浏览器
2. 获取电视的 IP 地址和调试端口
3. 在电脑浏览器中打开 `chrome://inspect`
4. 配置远程调试连接

## 调试技巧

### HBuilderX 内置调试器
1. 点击菜单 "运行" -> "打开调试器"
2. 或按快捷键 `F12`
3. 使用 Chrome DevTools 进行调试

### 浏览器开发者工具
1. 在运行的项目中右键
2. 选择 "检查" 或 "审查元素"
3. 使用完整的 Chrome DevTools 功能

### 真机调试
1. 在真机上运行项目
2. 使用 `console.log()` 输出调试信息
3. 查看 HBuilderX 控制台日志
4. 使用 vConsole 等移动端调试工具

### 网络请求调试
1. 打开浏览器开发者工具
2. 切换到 "Network" 标签
3. 查看所有网络请求
4. 检查请求参数、响应数据、状态码

## 代码编辑

### 代码提示
HBuilderX 内置了 Vue 3 和 uni-app 的代码提示,输入代码时会自动显示提示。

### 代码格式化
1. 点击菜单 "工具" -> "插件安装"
2. 安装 "uni-app" 官方插件
3. 使用快捷键 `Ctrl + Shift + F` (Windows) / `Cmd + Shift + F` (Mac) 格式化代码

### 代码片段
HBuilderX 支持代码片段功能:
1. 输入代码片段前缀
2. 按 `Tab` 键展开完整代码
3. 常用片段: `v-` (Vue), `uni-` (uni-app)

## 项目配置

### 环境变量配置
1. 在项目根目录创建 `.env.development` (开发环境)
2. 在项目根目录创建 `.env.production` (生产环境)
3. 配置 API 地址等环境变量

### API 代理配置
编辑 `vite.config.js`:
```javascript
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:3000',
      changeOrigin: true,
    }
  }
}
```

### 页面配置
编辑 `pages.json`:
- 配置页面路径和样式
- 配置全局样式
- 配置底部导航栏

## 常见问题

### Q: 运行时提示 "依赖未安装"
A: 在终端中执行 `npm install` 重新安装依赖

### Q: 运行时白屏
A: 打开浏览器开发者工具控制台,查看错误信息

### Q: API 请求失败
A: 检查:
1. 后端服务是否启动
2. API 地址配置是否正确
3. 代理配置是否生效
4. 是否存在跨域问题

### Q: 样式不生效
A: 检查:
1. SCSS 是否正确编译
2. 样式选择器是否正确
3. 是否有样式优先级冲突

### Q: 微信小程序运行失败
A: 检查:
1. 微信开发者工具是否正确安装
2. `manifest.json` 中的 appid 是否配置
3. 是否符合微信小程序的 API 限制

## 性能优化

### 减少包体积
1. 使用按需引入
2. 清理未使用的依赖
3. 压缩图片资源
4. 使用代码分割

### 提升加载速度
1. 启用 gzip 压缩
2. 使用 CDN 加速
3. 实现懒加载
4. 优化首屏渲染

### 优化电视端体验
1. 使用虚拟滚动
2. 减少 DOM 节点数量
3. 优化图片加载
4. 使用硬件加速

## 发布打包

### H5 打包
1. 点击菜单 "发行" -> "网站-H5手机版"
2. 配置打包选项
3. 点击 "发行"
4. 在 `unpackage/dist/build/h5` 目录查看打包结果

### 微信小程序打包
1. 点击菜单 "发行" -> "小程序-微信"
2. 配置打包选项
3. 点击 "发行"
4. 在 `unpackage/dist/build/mp-weixin` 目录查看打包结果
5. 使用微信开发者工具上传代码

### APP 打包
1. 点击菜单 "发行" -> "原生App-云打包"
2. 选择证书和打包参数
3. 点击 "打包"
4. 等待打包完成,下载 APK/IPA 文件

## 插件推荐

## 快捷键

- `Ctrl + S` / `Cmd + S`: 保存文件
- `Ctrl + Z` / `Cmd + Z`: 撤销
- `Ctrl + Y` / `Cmd + Y`: 重做

- `Ctrl + D` / `Cmd + D`: 选中相同单词
- `Ctrl + Shift + K` / `Cmd + Shift + K`: 删除当前行
